# Headline timings

Each entry is the median of the per-process medians of valid live rows; runs and distinct sweep counts are shown. Identical copies count once. Re-measurements replace rows only through explicit supersession (the archived superseded.jsonl is excluded), never by choosing the latest timestamp. Configuration groups retain effective options, library versions, compiler/flags, loaded libraries, thread/NUMA conditions and the epochs/repeats/warm-up protocol. check.ok=false, nonfinite losses and invalid timing rows use the same rejection rule as plots.

Training uses the median of steady_epochs_s when available, then steady_epoch_s, with call-level time as a labelled fallback for old rows. Within-process IQR is not between-process uncertainty; old rows without steady_iqr_s are marked not recorded. Inference uses the whole predict call.
